# Последний расклад

**Последний расклад** — мрачный браузерный карточный roguelike без фреймворков и серверной части. Игра сохраняет прогресс в браузере, работает офлайн после первого запуска и поддерживает установку как PWA.

## Текущая версия: 0.2.0

Версия 0.2 превращает ранний боевой прототип в полноценный забег с маршрутом, экономикой и постоянной прогрессией.

### Игровой цикл

- два акта по семь рядов маршрута;
- обычные и элитные бои;
- отдельный босс в конце каждого акта;
- случайные события с несколькими решениями;
- привалы с лечением, тренировкой и улучшением карт;
- магазин с картами, артефактами и удалением карт;
- сокровищницы с выбором артефакта;
- награды после боя;
- постоянная эссенция и открытие новых карт между забегами.

### Контент

- 25 игровых карт и отдельная карта-проклятие;
- улучшенные версии всех игровых карт;
- 12 противников с разными шаблонами действий;
- 14 артефактов;
- 5 случайных событий;
- 3 варианта карты маршрута;
- двухфазный финальный босс.

### Боевая система

- здоровье, броня и энергия;
- сила, слабость, уязвимость, ожог, шипы и возмездие;
- карты с X-стоимостью;
- исчезающие карты;
- добор, сброс и перемешивание;
- заранее показанные намерения противников;
- сохранение в любой момент;
- автоматическое продолжение незавершённого хода врага после перезагрузки.

## Запуск

Для корректной загрузки игрового пакета нужен локальный HTTP-сервер:

```bash
python -m http.server 8000
```

После запуска откройте `http://localhost:8000`.

При первом открытии загрузчик проверяет SHA-256 пакета, распаковывает игровые файлы в памяти и запускает игру. Service Worker сохраняет загрузчик и пакет для последующей офлайн-работы.

## Управление

- нажмите на доступный узел маршрута, чтобы перейти к нему;
- нажмите на карту, чтобы разыграть её;
- нажмите **«Завершить ход»** или клавишу `Пробел`, чтобы передать ход противнику;
- кнопки в верхней панели открывают колоду, артефакты и переключают звук;
- `Esc` закрывает просмотр колоды.

## Исходники и проверка

Проверенная исходная сборка хранится в `.upgrade/part00.txt` — `.upgrade/part06.txt` как gzip-архив с контрольной суммой. Это не минифицированный бинарник: архив содержит обычные `index.html`, `styles.css`, `data.js`, `game.js`, манифест, Service Worker, документацию и валидатор данных.

Распаковать читаемые исходники:

```bash
python scripts/unpack-bundle.py build-source
```

Проверить их:

```bash
node --check build-source/data.js
node --check build-source/game.js
node --check build-source/sw.js
node build-source/scripts/validate-data.js
```

Валидатор проверяет ссылки между картами, противниками, пулами, маршрутами и постоянными открытиями. Те же проверки выполняются в GitHub Actions.

## Структура репозитория

- `index.html` — проверяющий загрузчик и точка входа;
- `.upgrade/part*.txt` — полный проверенный исходный пакет версии 0.2;
- `manifest.webmanifest` — параметры установки приложения;
- `sw.js` — офлайн-кэш загрузчика и пакета;
- `scripts/unpack-bundle.py` — распаковка исходников для разработки;
- `CHANGELOG.md` — история версий.
