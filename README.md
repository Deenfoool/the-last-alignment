# Последний расклад

Браузерный карточный roguelike без зависимостей и сборщика. Игра запускается прямо из `index.html`.

## Что уже работает

- пошаговый бой с заранее показанным намерением врага;
- здоровье, броня, энергия, сила и возмездие;
- стартовая колода из 10 карт;
- добор, сброс и перемешивание колоды;
- 13 видов карт;
- награда из трёх случайных карт после победы;
- четыре последовательных противника, включая босса;
- восстановление здоровья между боями;
- сохранение текущего забега через `localStorage`;
- адаптивный интерфейс для компьютера и телефона.

## Запуск

Откройте `index.html` в современном браузере. Для локального сервера можно выполнить:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Управление

Нажмите на карту, чтобы разыграть её. Когда энергия закончится или нужные действия выполнены, нажмите **«Завершить ход»**.

## Структура

- `index.html` — разметка игрового экрана;
- `styles.css` — визуальный стиль и адаптивность;
- `game.js` — карты, противники, бой, награды и сохранение.
