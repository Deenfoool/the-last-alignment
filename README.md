# Битая масть

**Битая масть** — мрачный кроссплатформенный карточный roguelike с дуэлями против разных дилеров, мемными картами-пародиями, маршрутами, событиями и забегами с полной потерей прогресса после поражения.

Технический slug проекта: `bitaya-mast`.

## Состояние разработки

Текущий опубликованный прототип сохраняет прежний roguelike-забег, пока новая игра поэтапно строится поверх него. Полный план находится в [`ROADMAP.md`](ROADMAP.md).

### Завершено ранее

- браузерный прототип без серверной части;
- карта маршрута, события, отдых, торговец и сокровища;
- сохранение в браузере и офлайн-режим;
- визуальный слой и базовые анимации;
- защита от проблем с WebView, кэшем и `localStorage`.

### Этап 1: фундамент новой дуэли

В `src/core/battle-engine.js` добавлено независимое от интерфейса боевое ядро:

- детерминированная случайность с `seed`;
- отдельные состояния игрока и дилера;
- колода, рука, сброс и изгнание у обеих сторон;
- здоровье, щит, энергия, статусы и раунды;
- урон, защита, лечение и эффекты;
- кража, блокировка, поломка и сжигание карт;
- команды `playCard`, `endTurn`, `discardCard`, `chooseTarget`;
- единый журнал событий и команд;
- повтор матча по исходной конфигурации и журналу;
- проверка невозможных состояний;
- версионирование и миграция сохранений.

Подробности: [`docs/BATTLE_ENGINE.md`](docs/BATTLE_ENGINE.md).

## Проверка нового боевого ядра

Нужен Node.js 22 или новее:

```bash
node --check src/core/battle-engine.js
node --check src/core/sample-cards.js
node scripts/test-battle-engine.js
```

Тесты проверяют детерминированность, смену ходов, зоны карт, урон, щит, лечение, кражу, поломку, сжигание, бесполезную карту, повтор матча и миграцию сохранения.

## Запуск опубликованного прототипа

Для корректной загрузки игрового пакета нужен локальный HTTP-сервер:

```bash
python -m http.server 8000
```

После запуска откройте `http://localhost:8000`.

При первом открытии загрузчик проверяет SHA-256 пакета, распаковывает игровые файлы в памяти и запускает игру. Service Worker сохраняет приложение для последующей офлайн-работы.

## Структура репозитория

- `index.html` — точка входа и проверяющий загрузчик;
- `brand-runtime.js` — применение названия «Битая масть» к старому прототипу во время миграции;
- `compatibility-runtime.js` — совместимость браузеров и диагностика ошибок;
- `src/core/battle-engine.js` — новое детерминированное боевое ядро;
- `src/core/sample-cards.js` — тестовые карты первого этапа;
- `scripts/test-battle-engine.js` — автоматические тесты ядра;
- `docs/BATTLE_ENGINE.md` — архитектура и API боя;
- `.upgrade/part*.txt` — проверенный пакет старого прототипа;
- `manifest.webmanifest` — параметры PWA;
- `sw.js` — офлайн-кэш;
- `ROADMAP.md` — план до первой полноценной играбельной версии.

## Принцип разработки

Крупные этапы выполняются в отдельных ветках и попадают в `main` через pull request. Этап закрывается только после автоматических проверок, проверки сохранений и полного пользовательского сценария на ПК и телефоне.
