# Битая масть

**Битая масть** — мрачный кроссплатформенный карточный roguelike с дуэлями против разных дилеров, мемными картами-пародиями, маршрутами, событиями и забегами с полной потерей прогресса после поражения.

Технический slug проекта: `bitaya-mast`.

## Текущий этап

Главная страница содержит вертикальный срез новой дуэли:

- дилер за столом в среднепиксельном мрачном стиле;
- HUD здоровья, щита, энергии, раунда и текущего хода;
- физические стопки колоды и сброса;
- веер интерактивных карт;
- десять стартовых карт с отдельными иллюстрациями;
- намерение дилера, фиксированный таймер и автоматическое завершение хода;
- бот, который разыгрывает карты из собственной руки по правилам общего движка;
- анимации раздачи, розыгрыша, урона, защиты и действий дилера;
- победа, поражение, перезапуск и сохранение незавершённого боя;
- адаптация под мышь, клавиатуру и сенсорный экран.

Старый roguelike-прототип сохранён на странице [`legacy.html`](legacy.html) и продолжает использовать прежние сохранения.

Полный план разработки находится в [`ROADMAP.md`](ROADMAP.md).

## Боевое ядро

`src/core/battle-engine.js` не зависит от DOM и конкретного бота. Оно поддерживает:

- детерминированную случайность с `seed`;
- отдельные состояния игрока и дилера;
- колоду, руку, сброс и изгнание обеих сторон;
- здоровье, щит, энергию, статусы и раунды;
- урон, защиту, лечение и эффекты;
- кражу, блокировку, поломку и сжигание карт;
- журнал команд и воспроизведение матча;
- версионирование и миграцию сохранений.

Документация: [`docs/BATTLE_ENGINE.md`](docs/BATTLE_ENGINE.md).

## Запуск

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`.

Новая дуэль запускается сразу. Старый забег доступен по адресу `http://localhost:8000/legacy.html`.

## Проверки

Нужен Node.js 22 или новее:

```bash
node --check src/core/battle-engine.js
node --check src/data/stage2-cards.js
node --check src/ui/stage2-app.js
node scripts/test-battle-engine.js
node scripts/test-stage2-battle.js
```

## Структура

- `index.html` — новый экран дуэли;
- `legacy.html` — сохранённый предыдущий прототип;
- `styles/stage2.css` — адаптивный пиксельный интерфейс;
- `src/core/battle-engine.js` — детерминированное боевое ядро;
- `src/data/stage2-cards.js` — десять карт вертикального среза;
- `src/ui/stage2-app.js` — интерфейс, бот, анимации, таймер и сохранение;
- `src/data/stage2-assets-*.js` содержат оптимизированные встроенные изображения сцены и карт;
- `docs/VISUAL_GUIDE.md` — правила визуального стиля;
- `sw.js` — офлайн-кэш новой и старой версий;
- `ROADMAP.md` — план до первой полноценной играбельной версии.

## Принцип разработки

Крупные этапы выполняются в отдельных ветках и попадают в `main` через pull request. Этап закрывается только после автоматических проверок, проверки сохранений и полного пользовательского сценария на ПК и телефоне.
