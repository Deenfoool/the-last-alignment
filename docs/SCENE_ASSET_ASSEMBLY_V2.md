# Сборка ассетов сцены V2

Сцена больше не должна быть одной плоской картинкой. Она собирается из независимых слоёв в координатах master frame 1920×1080.

## Порядок слоёв

1. `background.svg` — комната без дилера, карт и интерфейса.
2. `ambient.svg` — верхний янтарный свет.
3. `dealer-atlas.svg` — активный дилер на прозрачном фоне.
4. `table.svg` — передний край стола и игровые зоны.
5. `dust.svg` — необязательная пыль.
6. `vignette.svg` — затемнение краёв.

## Точки привязки

Все координаты хранятся в `src/data/scene-asset-manifest.js` как доли кадра. Отдельный набор координат используется на экранах до 760 px.

## Правила экспорта

- фон не содержит дилера, HUD и карт;
- дилеры используют общий атлас 7×1;
- альфа-канал обязателен для дилеров и эффектов;
- каждый SVG использует `viewBox="0 0 1920 1080"`;
- механика не зависит от наличия декоративных слоёв;
- обязательные слои имеют fallback через старую сцену.

Этап 8 подключает этот пакет к основному бою и заменяет старые встроенные изображения.
