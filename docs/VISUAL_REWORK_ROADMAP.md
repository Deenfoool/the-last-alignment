# Roadmap визуальной переработки «Битой масти»

Этот план не переписывает готовую механику игры. Он заменяет визуальную подачу, которая не попала в пользовательский референс.

## Этап 2. Master frame

- [ ] один эталонный кадр боя 16:9;
- [ ] крупный центральный дилер;
- [ ] фронтальная камера;
- [ ] левый HUD;
- [ ] физический таймер;
- [ ] веер цельных карт;
- [ ] правильный свет и глубина;
- [ ] версия для ПК и проверка мобильного кадрирования;
- [ ] утверждение пользователем до нарезки ассетов.

## Этап 3. Система физических карт

- [ ] шаблоны размеров и пропорций;
- [ ] единые правила перспективы и износа;
- [ ] 10 эталонных карт первой руки;
- [ ] отсутствие механического текста на лице;
- [ ] читаемость в веере;
- [ ] мобильная версия;
- [ ] экспорт оптимизированных WebP/PNG.

## Этап 4. Tooltip и выбор карты

- [ ] hover на ПК;
- [ ] подъём выбранной карты;
- [ ] tooltip над картой;
- [ ] первый тап выбирает карту;
- [ ] второй тап разыгрывает;
- [ ] адаптивная панель для узкого экрана;
- [ ] клавиатурная доступность;
- [ ] пауза таймера при системных окнах, но не при обычном hover.

## Этап 5. Семь дилеров

- [ ] единая постановка и масштаб;
- [ ] семь уникальных силуэтов;
- [ ] отдельные руки и карты;
- [ ] реакции на урон, щит, победу и поражение;
- [ ] совместимость с одной сценой и освещением;
- [ ] оптимизация ассетов.

## Этап 6. Diegetic UI

- [ ] HUD игрока и противника;
- [ ] физический таймер;
- [ ] намерение дилера;
- [ ] журнал и подсказки;
- [ ] кнопки и системные окна;
- [ ] экран «Моя колода» в том же языке;
- [ ] отсутствие чистых веб-панелей.

## Этап 7. Нарезка и сборка ассетов

- [ ] фон без дилера;
- [ ] дилеры с прозрачностью;
- [ ] карты отдельно;
- [ ] HUD и таймер отдельно;
- [ ] эффекты света и дыма;
- [ ] таблица размеров и точек привязки;
- [ ] лицензирование и отсутствие чужих логотипов в финальных ассетах.

## Этап 8. Внедрение в игру

- [ ] замена текущей сцены;
- [ ] замена текущих карт;
- [ ] замена портретов дилеров;
- [ ] новая система раскладки;
- [ ] desktop/mobile поведение;
- [ ] сохранение всей механики и старых сохранений;
- [ ] обновление Service Worker.

## Этап 9. Полировка и визуальная приёмка

- [ ] полный забег на ПК;
- [ ] ключевой бой на телефоне;
- [ ] анимация наведения и розыгрыша;
- [ ] реакции дилера;
- [ ] свет, пыль, дым и шум;
- [ ] производительность;
- [ ] отсутствие визуальных расхождений с библией;
- [ ] утверждение пользователем.

## Правило продвижения

Нельзя переходить к массовой генерации карт и дилеров, пока пользователь не утвердил master frame этапа 2. Любой новый ассет сверяется с [`VISUAL_BIBLE_V2.md`](VISUAL_BIBLE_V2.md).
