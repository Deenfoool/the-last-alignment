# Внедрение визуальной сцены v2

Новая сцена загружается совместимым слоем из `stage3-initial-save-guard.js`, который уже присутствует в основной цепочке `index.html`.

## Порядок загрузки

1. Подключаются стили diegetic UI, физических карт и слоёной сцены.
2. Загружается манифест `scene-asset-manifest.js`.
3. Сборщик создаёт фон, свет, дилера, стол, пыль и виньетку.
4. Проверяется доступность всех обязательных слоёв.
5. После успешной проверки корню документа назначается `visual-v2-ready`.
6. При любой ошибке включается `visual-v2-fallback`, и старый визуал остаётся рабочим.

## Дилеры

Активный дилер берётся из выбранного элемента интерфейса или ключа `bitaya-mast-stage6-dealer-v1`. Сборщик реагирует на клик, изменение, событие `bitaya:dealer-changed`, изменение localStorage и смену классов выбора.

## Карты

Модуль `physical-card-interactions.js` включён в основной бой. На ПК описание открывается при наведении, на сенсорном экране первый тап выбирает карту, второй разыгрывает.

## PWA

Service Worker v14 кэширует все слои сцены, дилерский атлас, стартовый лист карт, стили и модули взаимодействия.
