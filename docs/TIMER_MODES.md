# Режимы времени

Этап 3 превращает таймер из жёстко заданного числа в настройку конкретной сдачи.

## Пресеты

| Режим | Время на ход | Назначение |
|---|---:|---|
| Классика | без ограничения | сюжетное прохождение и спокойная тактика |
| Быстрый | 60 секунд | умеренное давление без спешки |
| Хардкор | 30 секунд | быстрые решения и высокий риск |
| Свой режим | 10–180 секунд | пользовательская длительность |

## Последствия окончания времени

- `end_turn` — ход немедленно заканчивается;
- `discard_random` — случайная карта из руки уходит в сброс, затем ход заканчивается;
- `damage` — игрок получает 3 урона с учётом щита, затем ход заканчивается;
- `dealer_energy` — после завершения хода дилер получает 1 дополнительную энергию.

## Команда боя

Истечение времени оформлено командой:

```js
{
  type: "expireTurn",
  actorId: "player",
  penalty: "discard_random",
  amount: 1
}
```

Команда обрабатывается `src/core/timed-battle-engine.js`, записывается в `commandLog`, получает `preHash` и `postHash` и поддерживается воспроизведением матча.

## Защита состояния

- команда принимается только от активной стороны;
- во время анимации карты таймер приостанавливается;
- во время хода дилера таймер не запущен;
- повторное срабатывание на том же ходу блокируется номером хода и флагом перехода;
- скрытая вкладка ставит отсчёт на паузу;
- оставшееся время сохраняется вместе с боем;
- сохранение этапа 2 мигрирует в пользовательский режим на 45 секунд без штрафа сверх завершения хода.

## Хранение

- настройки: `bitaya-mast-stage3-settings-v1`;
- состояние боя: `bitaya-mast-stage3-battle-v2`;
- старый ключ этапа 2 читается один раз и затем удаляется после успешной миграции.
