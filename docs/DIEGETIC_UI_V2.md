# Diegetic UI V2

Этап 6 визуальной переработки переводит интерфейс из обычных веб-панелей в физический язык сцены.

## Материалы

- HUD: потёртый металл и тёмное дерево.
- Таймер: отдельный механический прибор с винтами и экраном.
- Намерение: приколотая табличка.
- Журнал: тёмная бумажная лента.
- Завершение хода: тяжёлая механическая клавиша.
- Системные окна: шкафы/панели с внутренней рамкой.
- Tooltip: тёмная карточная этикетка над физической картой.

## Правила

Интерфейс не использует белые панели, glassmorphism, чистые SaaS-кнопки и холодные неоновые поверхности. Обычный просмотр карты не останавливает таймер. Механика боя и сохранения не меняются.

## Мобильная версия

На узком экране сохраняется иерархия: показатели, сцена, таймер, действие и рука. Декоративные наклоны отключаются, чтобы элементы не выходили за viewport.
